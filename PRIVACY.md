# Политика конфиденциальности — Конвертер цен

Последнее обновление: 26.09.2026

## Что делает расширение

«Конвертер цен» находит цены в тексте открытых вами страниц и показывает
их эквивалент в выбранной вами валюте. Весь разбор текста и вставка
конвертированных цен происходит **локально в вашем браузере**.

## Какие данные собираются

Расширение **не собирает, не хранит и не передаёт** какие-либо личные
данные, историю посещений или содержимое просматриваемых страниц на
какие-либо серверы, включая серверы разработчика.

Единственные сетевые запросы, которые делает расширение:

- `https://api.frankfurter.dev/*` — публичный API курсов Европейского ЦБ
  (без ключей, без идентификаторов пользователя);
- `https://open.er-api.com/*` — публичный API рыночных курсов валют
  (без ключей, без идентификаторов пользователя).

Эти запросы получают только текущие курсы валют и не содержат никакой
информации о пользователе, посещаемых сайтах или введённых данных.

## Хранение настроек

Настройки расширения (язык интерфейса, целевая валюта, режим показа,
свои курсы и т.п.) хранятся только локально в `chrome.storage.local`
на вашем устройстве и никуда не отправляются.

## Разрешения

- `storage` — для хранения настроек локально.
- `alarms` — для периодического обновления курсов валют (раз в 3 часа).
- `activeTab` — для показа статистики по текущей открытой странице в
  окне настроек.
- Доступ к содержимому страниц нужен исключительно для поиска и
  отображения цен на странице; содержимое страниц не читается для
  каких-либо иных целей и никуда не передаётся.
