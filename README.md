# Конвертер цен (Price Converter)

Расширение для Chrome / Edge (Manifest V3): находит цены в тексте любой страницы и
показывает их эквивалент в валюте на ваш выбор — рубли, доллары, евро и ещё полтораста
других. Интерфейс — на русском, английском и арабском (с поддержкой RTL). Сборка не
нужна — чистый JS, грузится как есть.

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `ruble-prices`.
3. Иконка ₽ появится на панели; там же настройки.

## Языки и целевая валюта

- **Язык интерфейса**: русский / English / العربية — переключается прямо в попапе
  (кнопки RU / EN / AR), без перезапуска. По умолчанию — «авто»: подстраивается под язык
  браузера, арабский включает зеркальную (RTL) раскладку попапа.
- **Валюта, в которую переводим**: не только рубли — можно выбрать доллары, евро, фунты,
  юани, дирхамы, лиры и другие из списка «Показывать цены в». Любая цена, найденная на
  странице (в любой валюте, кроме уже выбранной целевой), пересчитывается в неё через
  общий курс к рублю.
- **Свой курс** можно задать между любыми двумя валютами, не обязательно к рублю:
  `1 USD = 95 ₽`, а можно и `1 SAR = 0.2667 USD` — вторая валюта в цепочке досчитывается
  через свой или официальный курс автоматически. Подробнее — ниже.

## Что умеет

- **Символы и коды**: `$ € £ ¥ ₩ ₹ ₺ ₪ ₫ ₱ ฿ ₦ ₴ ₸ ₾ ₼ ֏ ﷼`, составные `C$ A$ HK$ R$ S$ NZ$ NT$ MX$ US$`,
  ISO-коды (`USD`, `EUR`, `CNY`, `PLN`, …), написания магазинов Залива (`SR`, `QR`, `Dhs`, `ر.س`,
  новый знак риала `⃁`), локальные написания (`zł`, `Kč`, `Ft`, `грн`, `тг`)
  и слова («20 евро», «3 500 тенге», «45 dollars»).
- **Обе позиции маркера**: `$19.99` и `19,99 €`.
- **Цены, разбитые по элементам**: магазины часто верстают
  `<span class="price__currency">SR</span> 399` — символ валюты и число лежат в разных
  узлах DOM. Такие цены склеиваются по инлайновому контейнеру и считаются как одна.
- **Форматы чисел**: `1,234.56`, `1 234,56`, `1.234.567`, а также `$1.2M`, `$49k`, `2.5 млн USD`.
- **Динамические страницы**: MutationObserver подхватывает цены, подгруженные позже,
  плюс обход открытых shadow root и работа во фреймах.
- **Три режима показа**: дописать `≈ 105 870 ₽` рядом, заменить оригинал (он остаётся в тултипе)
  или только подсветить с подсказкой при наведении.
- **Свой курс**: задаётся как «1 [валюта] = [число] [любая другая валюта]» — например
  `1 USD = 95 ₽` или `1 SAR = 0.2667 USD`. Вторую валюту в паре расширение само досчитывает
  до рубля через официальный курс (или через ещё один ваш свой курс, если он тоже задан —
  цепочки поддерживаются, круговые ссылки просто игнорируются). Такой курс перебивает курс
  источника для своей валюты. Галка «Остальные валюты — от моего курса» масштабирует все
  прочие валюты в той же пропорции (якорь — USD, если задан, иначе EUR, иначе первая
  заданная валюта).
- **Наценка к курсу** в процентах — чтобы сразу видеть цену с комиссией банка.
  Считается поверх курса, в том числе своего.
- **Порог**: не показывать конверсию для сумм дешевле N ₽.
- **Выключение на конкретном сайте** одной галкой.

Цены, уже указанные в рублях, не трогаются. Не трогается и текст внутри
`input`, `textarea`, `code`, `pre`, `script` и contenteditable-полей.

## Курсы

- **ЦБ РФ** — `cbr-xml-daily.ru` (официальный, ~40 валют), источник по умолчанию.
- **Рыночный** — `open.er-api.com` (~160 валют).

Оба источника опрашиваются вместе: выбранный задаёт курс, второй дополняет валюты,
которых у первого нет. Данные кэшируются в `chrome.storage.local` и обновляются
раз в 3 часа будильником, плюс кнопкой «Обновить курс». Ключи API не нужны.

## Структура

| Файл | Назначение |
| --- | --- |
| `manifest.json` | манифест MV3 |
| `background.js` | service worker: загрузка, слияние и кэш курсов |
| `lib/parser.js` | поиск цен в тексте и разбор чисел (работает и в Node) |
| `lib/config.js` | настройки, конверсия в любую целевую валюту, форматирование |
| `lib/i18n.js` | словари ru/en/ar, определение языка, RTL |
| `content/converter.js` | обход DOM, вставка конвертированных цен, MutationObserver |
| `popup/` | окно настроек (язык, целевая валюта, режимы) |
| `_locales/` | локализация имени и описания расширения для chrome://extensions |
| `test/parser.test.js` | тесты парсера |
| `test/rates.test.js` | тесты курсов: ручной курс, пересчёт, наценка |
| `test/fixture.html` | стенд страницы с ценами (заглушка `chrome.*`) |
| `test/popup-preview.html` | стенд окна настроек вне расширения |
| `test/live-check.html` | прогон по сохранённой копии реального магазина |

## Тесты

```bash
node test/parser.test.js
node test/rates.test.js
```

Стенды открываются в браузере без установки расширения: они подменяют
`chrome.storage`/`chrome.runtime` фиктивными курсами и запускают настоящий content script.
Файлы нужно отдавать по http (из `file://` браузер не выполнит скрипты) — например,
любым статическим сервером из корня проекта.

- `test/fixture.html` — синтетические цены, включая разбитые по элементам.
- `test/live-check.html` — грузит в iframe сохранённую копию страницы магазина
  и инжектит в неё content script. Копию положить рядом под именем `_live-jarir.html`:

```bash
curl -A "Mozilla/5.0" "https://www.jarir.com/sa-en/huawei-watch-fit-4-smartwatch-657289.html" -o test/_live-jarir.html
```
